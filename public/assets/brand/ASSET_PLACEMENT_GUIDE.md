### 배치 금지
- **히어로에 AI 이미지 사용 금지.** 히어로는 직접 촬영한 평택지원 창밖 사진 전용 자리다. 촬영 전까지는 현행 이미지를 유지한다. `window-view.webp`를 히어로에 넣지 않는다.
- **변호사 프로필 사진을 AI 이미지로 대체 금지.**
- **성공사례·판결문 영역에 AI 이미지 사용 금지.** (사실 증거 영역에 생성 이미지가 섞이면 신뢰가 깨진다)

## 2. 위치별 구현 사양

### 2-1. 두 번째 섹션 배경 영상 (`hands-pen.mp4`)

```html
<video
  autoplay muted loop playsinline
  poster="/assets/brand/hands-pen.webp"
  preload="metadata"
  aria-hidden="true"
  class="absolute inset-0 w-full h-full object-cover">
  <source src="/assets/brand/hands-pen.mp4" type="video/mp4" />
</video>
```

- `muted` 필수. 소리 있는 자동재생 절대 금지.
- 텍스트 가독성을 위해 영상 위에 오버레이 1겹: `bg-black/40` ~ `bg-black/50` 범위에서 조정 (기존 텍스트 색 대비 확인).
- **모바일(md 미만)에서는 영상을 로드하지 않고 poster 이미지만 표시한다.** (데이터 사용량·배터리 배려)
  - 구현: `matchMedia('(min-width: 768px)')` 조건부 렌더 또는 `<video>` 대신 배경 이미지 폴백.
- `prefers-reduced-motion: reduce` 사용자에게는 영상 대신 정지 이미지를 보여준다.
- 파일이 5MB를 넘으면 삽입하지 말고 보고한다 (재인코딩 필요).

### 2-2. 상담 신청 페이지 (`consult-chairs.webp`)

- 위치: 페이지 타이틀("온라인 상담 신청") 아래, 안심 카피 2줄("사소한 질문이라도 괜찮습니다...") **위** 또는 좌우 분할 레이아웃의 한쪽.
- 데스크톱: 좌측 이미지 / 우측 폼의 2단 구성 권장. 모바일: 이미지 상단 1장 (높이 200~260px, `object-cover`).
- 이미지에 텍스트를 얹지 않는다. 필터·그레이스케일 처리하지 않는다 (따뜻한 원본 톤이 목적).

### 2-3. 법인 소개 보조 (`bookshelf.webp`)

- 위치: [작업 4]에서 추가하는 희소성 단락("동시에 진행하는 사건 수를 의도적으로 제한합니다") 옆 또는 위.
- 크기: 본문 폭의 40~50%, 우측 배치 권장. 장식이지 주인공이 아니다.

### 2-4. 블로그 헤더 (`desk-still.webp`)

- 최신 법률 정보 목록 페이지 상단 배너 + 게시글 상세에 **대표 이미지가 없는 글의 기본(fallback) 썸네일**로 사용.
- 관리자가 업로드한 대표 이미지가 있으면 그것을 우선한다. AI 이미지가 실제 사건 이미지처럼 보이는 자리에는 쓰지 않는다.
- 배너로 쓸 때 높이 180~240px, `object-cover`, 위에 페이지 타이틀 텍스트. 오버레이 `bg-black/30` 내외.

### 2-5. 영문 섹션 (`window-view.webp`)

- English Legal Services 섹션/페이지 상단.
- 캡션·alt에 특정 장소명을 쓰지 않는다 (실제 평택 사진이 아니므로 "Pyeongtaek office view" 같은 표기 금지).

### 2-6. 미사용 자산

- `consult-chairs.mp4`, `desk-still.mp4`는 이번 작업에서 삽입하지 않는다. `/public/assets/brand/`에 보관만 한다. (영상 1개 원칙)

## 3. 공통 기술 기준

1. **alt 텍스트** (스크린리더·SEO):
   - hands-pen: `만년필을 들고 기록을 준비하는 변호사의 손`
   - consult-chairs: `법무법인 명 상담실의 좌석`
   - desk-still: `변호사 책상 위의 책과 만년필`
   - bookshelf: `사무실 서가`
   - window-view: `사무실 창밖 풍경`
   - 배경 영상은 `aria-hidden="true"` 처리하고 alt 서술은 poster 쪽에 두지 않는다 (장식 요소).
2. **로딩**: 히어로 외 모든 이미지에 `loading="lazy"` + `decoding="async"`.
3. **용량 목표**: 이미지 1장당 300KB 이하 (초과 시 리사이즈: 최대 폭 1920px), 영상 5MB 이하.
4. **비율 고정**: 레이아웃 시프트 방지를 위해 컨테이너에 `aspect-ratio` 지정 (이미지 원본 비율 16:9 기준).
5. **일관 톤**: 삽입 시 CSS 필터(그레이스케일, 세피아, 과한 밝기 보정)를 추가하지 않는다. 원본 톤 유지가 원칙.

## 4. 삽입 전 품질 게이트 (사람이 확인)

Claude Code는 삽입 전 아래 확인을 사용자에게 요청한다. 하나라도 해당되면 해당 자산은 삽입 보류.

- [ ] 손가락 개수·형태 이상 없음 (hands-pen 이미지·영상)
- [ ] 이미지 어디에도 깨진 글자·유사 문자 없음 (책등, 종이, 창밖 간판 포함)
- [ ] 영상 루프 경계에서 튀는 프레임 없음 (끝→처음 전환 자연스러움)
- [ ] 영상에서 사물 형태가 변형(morphing)되는 구간 없음
- [ ] 피부·사물 질감이 플라스틱처럼 과하게 매끈하지 않음
- [ ] 5장의 이미지 색 톤이 서로 이질적이지 않음 (한 사무실로 보임)
