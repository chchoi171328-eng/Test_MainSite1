# 소식(주간 법률 소식) 페이지 구현 지시서 (Claude Code용)

> 결정: 소식 = **주간호 구조.** 게시판 하나, 주 1편, 한 편 안에 지난주의 법령
> 제·개정·판결 요약을 나열한다. 항목별 상세 페이지는 만들지 않는다.
> 시각 정본: `news-preview.html` (시안 A = 목록 / 시안 B = 주간호 본문).
> 현재 /news는 빈 껍데기 상태 — 이 지시서로 채운다.
> 콘텐츠 생산은 legal-news-writer 스킬이 담당하며, 이 지시서는 그릇만 만든다.

## 1. 콘텐츠 구조

```
/content/news/{slug}/index.mdx     # slug = 발행일 기반 (예: 2026-08-10)
```

frontmatter (주간호 단위):
```yaml
title: "8월 첫째 주 — 임대차 표준계약서 고시 개정 외 3건"
slug: "2026-08-10"
publishedAt: "2026-08-10"
periodStart: "2026-08-03"          # 다루는 기간
periodEnd: "2026-08-09"
items:                              # 목록 미리보기·메타 (본문과 순서 일치)
  - category: "law"                 # law(개정) | enforce(시행) | ruling(판결) | office(사무소)
    fields: ["real-estate"]         # 8분야 키 (복수 가능, 없으면 [])
    title: "주택임대차 표준계약서 고시 개정 — 관리비 항목 세분화"
  - category: "ruling"
    fields: ["construction"]
    title: "추가공사대금, 서면 합의 없어도 지시·시공 정황으로 인정"
---
(본문 — 아래 3절의 항목 블록 반복)
```

## 2. 목록 페이지 (/news)

시안 A 그대로:
- 인트로: "한 주의 법령 제·개정과 주요 판결을 정리해 올립니다."
  (기존 부제 교체. **발행 주기를 약속하는 문구 금지** — "매주 월요일" 류)
- 연도 그룹 라벨(골드) → 주간호 리스트: 좌열 **날짜만**(호수 없음), 명조 제목,
  그 아래 items에서 생성한 미리보기(카테고리 미니 태그 + 항목 제목을 " · "로 연결)
- 발행일 역순. 페이지네이션은 30편 넘으면 (당분간 불요)

## 3. 주간호 본문 페이지 (/news/{slug})

시안 B 그대로. 항목 블록 구조:

```html
<div class="news-item">
  <div class="ibadges"><span class="nbadge law">법령 개정</span><span class="ifield">부동산</span></div>
  <h2>주택임대차 표준계약서 고시 개정 — 관리비 항목 세분화</h2>
  <p>…요약 2~3문단…</p>
  <span class="iref">시행: 2026. 9. 1. 예정</span>            <!-- 해당 시에만 -->
  <div class="iguide"><span class="lb">관련 가이드</span><a href="/guides/real-estate/deposit-return">임대차보증금 반환</a></div>  <!-- 발행된 가이드만 -->
</div>
```

- 헤더: "주간 법률 소식"(골드 라벨, 호수 없음) + 제목 + "기간 | 발행일"
- 뱃지 스타일(시안 수치): 개정·시행 = 네이비 솔리드 / 판결 = 골드 아웃라인
  (#fdf9f0 배경) / 사무소 = 연회색. 분야 태그는 8분야 표시명(공유 매핑 사용)
- 관련 가이드 링크는 **발행된 가이드만** — 빌드 시 존재 검증, 없으면 렌더 생략
  (깨진 링크 금지)
- 푸터 고정 문구: "이 소식지는 지난 한 주의 법령·판결 중 실무에 영향이 있는 것을
  골라 요약한 것입니다. 요약은 이해를 위한 것으로, 개별 사안에 대한 법률 자문이
  아닙니다. — 법무법인 명"

## 4. 연결 지점

- /legal-info 허브 하단 "최근 소식" — 주간호 제목·날짜 3건 (기존 구조 규칙 유지)
- 메가 드롭다운 "소식" 링크는 현행 유지 (/news)
- sitemap: 주간호 전 경로, lastmod = publishedAt
- 주간호 title 태그: "{title} | 주간 법률 소식 | 법무법인 명"
