# A. 메인 히어로 캡션

> 대상: 메인 페이지(/) 히어로 섹션 (hero-court-view.webp 사용 구간)
> 히어로의 기존 헤드라인·서브 카피·버튼·오버레이는 **수정하지 않는다.**

## 1. 캡션 추가

히어로 섹션 우하단에 사진 설명 캡션을 추가한다.

- 문구 (글자 그대로, 변경 금지):
  `사무실에서 바라본 수원지방검찰청 평택지청 · 수원지방법원 평택지원`
  (사진 속 좌→우 순서와 일치: 왼쪽 건물 = 지청, 오른쪽 건물 = 지원)
- 위치: 히어로 섹션 기준 absolute, 우하단. right 20px / bottom 16px
- 스타일:
  - font-size 11.5px, font-weight 300, letter-spacing .02em
  - color: rgba(255,255,255,.55)
  - text-align: right, line-height 1.5
  - z-index: 오버레이 위, 콘텐츠와 동일 층 (미리보기 기준 z-11)
- 모바일(640px 이하):
  - font-size 10.5px, right 14px / bottom 12px, max-width 78%
  - 두 줄 줄바꿈 허용: `사무실에서 바라본` / `수원지방검찰청 평택지청 · 수원지방법원 평택지원`
    (미리보기처럼 <br> 고정 줄바꿈 또는 max-width에 의한 자연 줄바꿈 모두 가능)
- 히어로 하단 중앙에 스크롤 인디케이터 등 다른 요소가 있는 경우:
  캡션은 우하단 유지, 겹침이 생기면 캡션의 bottom 값을 인디케이터 위로 조정

## 2. 히어로 이미지 alt 텍스트 교체

hero-court-view.webp 의 alt를 다음으로 교체한다:

`법무법인 명 사무실에서 바라본 수원지방법원 평택지원과 수원지방검찰청 평택지청`

- 목적: 접근성 + "평택지원", "평택지청" 키워드의 텍스트 반영 (SEO)
- alt는 문장형이므로 기관 서열 순(법원 먼저)으로 표기 — 캡션(시각 순서)과 다른 것이 의도임

## 3. 변경 금지

- 히어로 헤드라인("모든 사건을 맡지는 않습니다."), 서브 카피, "법무법인 명 · 평택" 라인, 버튼 2종
- 오버레이 값(bg-brand-dark/70)
- 이미지 파일 자체 (향후 재촬영본으로 교체 시 파일만 교체하면 캡션·alt는 그대로 유효)

# B. 법인 소개 — 「일하는 방식」 항목 2개 추가

## 5. 대상과 작업

- 대상: `/about` 하단, 현재 아래 두 문장이 있는 섹션
  - "한 사건을 끝까지 책임지기 위해, 동시에 진행하는 사건 수를 의도적으로 제한합니다."
  - "상담부터 변론까지 같은 변호사가 담당합니다."
- 이 섹션에 **기존 2개 항목과 동일한 스타일로** 아래 2개를 추가한다.
  순서는 기존 2개 뒤(3번, 4번 위치).

**추가 항목 3**
```
연락을 주시면 늦어도 다음 영업일에는 담당 변호사와 직접 통화하실 수 있습니다.
```

**추가 항목 4**
```
법원에 제출하는 서면은 제출 전에 미리 보여드립니다. 사실관계 확인을 위해서도
필요한 절차입니다. 확정된 사실관계로 법리만 다투는 서면은 제출 후에 공유드리는
경우도 있지만, 원하시면 모든 서면을 보실 수 있습니다.
```

## 6. 변경 금지 (B)

- 기존 2개 항목의 문구·순서·스타일
- 섹션 제목 (현재 제목이 없다면 새로 만들지 않는다)
- 항목 4가 기존 항목들보다 길어 레이아웃이 어색해지면, **문구를 줄이지 말고**
  줄바꿈·행간으로 처리한다 (문구는 확정본이다)
