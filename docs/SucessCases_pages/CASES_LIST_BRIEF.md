# 성공사례 목록 카드 재설계 지시서 (Claude Code용)

> 전제: 성공사례 정적 전환(CASE_BOARD_BRIEF 작업 1~5)은 **완료된 상태**다.
> 이 지시서는 목록 카드 재설계와 강조색 정리만 다룬다.
> 시각 정본: `cases-list-preview.html` (데스크톱 3열 / 모바일 1열 고밀도).
> 현행 카드의 문제: 무정보 제목("사기 사건" 반복), 빨간 강조 텍스트, 잘린 발췌,
> 모바일 과대 카드(한 화면 1.5장).

## 1. frontmatter 필드 추가

`summary` 필드를 사례 frontmatter 스키마에 추가한다 (목록 카드용 한 줄 요약):

```yaml
summary: "거래 실패가 기망이었는지가 쟁점이 된 사건에서, 거래 경위 소명으로 무혐의 처분을 받았습니다."
```

- 기존 사례에는 **생성하지 않는다** (발췌 폴백 — 재생산 시 스킬이 채움)
- 신규·재생산 사례는 success-case-writer 스킬이 채워서 온다
  (규칙: 40~80자 완결 문장, 결과 포함, 말줄임 없음)

## 2. 카드 재설계 (preview 그대로)

카드 구성 순서:
1. **result 배지 — 네이비(#1E3A5F) 솔리드, 흰 글자** + category 배지(배경 #f1eee7,
   글자 #6b6353). 현행 아웃라인 스타일 폐기 — 결과가 카드의 첫 정보다
2. 제목 = **list_title** (Noto Serif KR, 17px 안팎)
3. 요약 = frontmatter **summary**. 없으면(기존 사례) 본문 첫 문단 발췌로 폴백 —
   `.case-brief`의 `<dl>` 텍스트가 발췌에 섞이면 안 된다
4. 푸터: "판결문 마스킹본" (회색 문서 아이콘 — **현행 초록 아이콘·초록 텍스트 제거**)
   + "자세히 →" (네이비)
- hover: 보더 짙어짐 + 옅은 그림자 (preview 수치)
- 카드 전체가 클릭 영역

## 3. 강조색 정리 (사이트 전역)

- 목록 발췌와 **상세 페이지 기존 본문**의 빨간색 강조(죄명 등)를 전부 제거한다 —
  일반 텍스트 또는 `<strong>`(검정 굵게)로. 빨강·초록 등 팔레트(네이비·골드) 밖
  강조색은 성공사례 영역 어디에도 남기지 않는다
- 제거 대상 목록을 보고한다 (몇 건에서 몇 곳)

## 4. 모바일 (≤680px)

- 카드 패딩 16px, 배지 11px, 요약 2줄 클램프(-webkit-line-clamp)
- 목표: 한 화면(375×740)에 카드 2.5~3장 노출
- 필터 칩은 가로 스크롤 또는 줄바꿈 허용

## 5. 분야 필터

- category 기준 칩: 전체 / 형사 / 민사 / 가사 / 부동산·건설 / 기업
- 사례 없는 분야는 칩 자체를 숨긴다 (기존 원칙)
- 선택 상태: 네이비 배경 흰 글자 (preview)

## 6. 완료 기준

- [ ] 목록이 cases-list-preview.html과 시각 일치 (배지 위계·요약·hover)
- [ ] 기존 사례(summary 없음)가 발췌 폴백으로 정상 표시, `<dl>` 텍스트 미노출
- [ ] 빨간·초록 강조가 목록·상세 어디에도 없음 + 제거 내역 보고
- [ ] 모바일 375px에서 한 화면 2.5장 이상
- [ ] 필터 동작, 빈 분야 칩 숨김
