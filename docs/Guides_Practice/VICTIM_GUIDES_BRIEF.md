## 0-1. 현행 수사 구조 반영 (전 편 공통 — 필수)

수사권 조정 이후의 절차를 기준으로 쓴다. 핵심: 경찰이 1차 수사종결권을 가지므로
사건은 **송치 / 불송치** 두 갈래로 갈리고, 피해자 불복은 결정의 주체에 따라
트랙이 다르다 — 경찰 불송치 → **이의신청**, 검사 불기소 → **항고 → 재정신청**.
관련 기한·절차는 개정 이력이 있으므로 **작성 시 현행법을 웹 검색으로 재검증**하고
확인 필요 목록에 반드시 포함한다.
