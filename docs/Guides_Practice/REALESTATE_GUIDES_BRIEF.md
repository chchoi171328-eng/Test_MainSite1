## 3. 편별 고정 참조

- 세부 페이지(/practice/real-estate) 확정 카피가 톤·용어 기준. 특히: "복잡한 법리를
  사실관계에 맞추는 것", 유형 9종 서술, 임차권등기명령 셀프 사실 서술, 권리금
  요건 중심 서술, 공유물분할 구조. **용어·수치가 세부 페이지와 어긋나면 안 된다.**
- 명도 관련 법률 수치(주택 2기/상가 3기, 갱신거절 통지기간, 갱신요구권 기간)는
  **웹 검색으로 현행 법령 재검증** 후 사용하고, 확인 필요 목록에 반드시 포함한다.
- 금액 표기: "만 원" 띄어쓰기 / 하한 "부터"

## 5. §9 노출 우선순위 (부동산은 10편이라 4건 초과)

세부 페이지 §9는 최대 4건이므로, 전 편 발행 후 `featured: true`를 다음 4편에
지정한다: 주택 명도 / 상가 명도 / 임대차보증금 반환 / 상가 권리금 회수.
(임대인·임차인 양쪽 대표 + 상가 특화 — 나머지는 /legal-info와 가이드 간
related로 발견된다.)
