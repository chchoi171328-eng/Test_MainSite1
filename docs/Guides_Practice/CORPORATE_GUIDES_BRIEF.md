> 보고 → 변호사 승인 → 발행)** / 판례 인용 금지 / 이미지 TODO 폴백 /

> 발행 우선순위: 8분야 중 마지막 (건설·부동산 1차 → 형사 → 피해자 → 민사 → 이혼 →
> 상속 → 이 분야).
>
> **실적 수위 (중요)**: 기업 법무는 수행 이력이 얇은 분야다(계약서 검토·작성,
> 분쟁 초기 대응, 노동청 조사·심판 대응 수행 / 정기자문·M&A 등 없음). 전 편에서
> 수행 실적을 암시·과장하는 표현 금지. 세부 페이지(/practice/corporate)와 동일한
> 사실 진술 수위를 유지한다. cert 언급 없음(기업은 cert 미표기 분야). 단, 노동청
> 조사·노동위원회 심판 대응은 실제 수행 분야이므로 그 사실 서술은 가능하다.

| 순서 | listingTitle | slug | 담당 검색 질의 | 구조 메모 |
|---|---|---|---|---|
| 1 | 계약서 검토 — 무엇을 보는가 | contract-review | 계약서 검토 항목, 계약서 확인할 것 | **기둥.** 3분면 구조(세부 페이지 FAQ 확장): 불리한 조항 / 분쟁 시 문제될 조항 / 빠진 조항. 자주 문제되는 조항 유형(대금·지급 조건, 해지, 손해배상·위약벌, 관할). **검토와 수정안 작성은 별개 업무이며 수정안은 추가 비용을 미리 안내한다는 경계**(세부 페이지 교정 사항 그대로) |
| 2 | 계약 해지·해제 통지 | termination-notice | 계약 해지 통지, 최고 통지 | 세부 페이지 §4-2 통찰의 확장 — **최고 통지 → 해지·해제 통지 순서**가 소송에서 다투어지는 구조. 통지를 미리 설계하면 소송 자산이 되고 협의의 계기도 된다는 양면. civil의 내용증명 편과 역할 분담(여긴 B2B 계약 국면) — 본문 크로스 링크 |
| 3 | 계약서 없이 거래해 온 관계 정리 | trade-agreement | 거래 기본계약서, 구두 계약 분쟁 | 세부 페이지 상황 리스트("계약서 없이, 오래된 양식으로")의 확장. 관행 거래의 위험이 현실화되는 순간들(단가 다툼·품질 클레임·거래 중단), 기본거래계약서로 정비하는 접근. 이미 분쟁 조짐이면 2번으로, 소송 국면이면 civil 물품대금 편으로(크로스 링크 — 거긴 소송, 여긴 예방) |
