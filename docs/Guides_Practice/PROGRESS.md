### civil
- **civil-procedure**: ①**가집행 선고·강제집행정지 — 조문(민소법 제213조 계열) 미인용 서술, 확인 요망** ②소액/단독/합의 재판부 구분 — 소가 기준 구체 금액 미기재(소액 3,000만 원 기준 미검증) ③사해행위 취소 언급(FAQ) — 제도 존재 수준 ④조정의 확정판결 동일 효력 — 조문 미인용 ⑤항소·상고 2주(제396조·제425조 준용)는 웹 검증 완료
- **when-sued**: ①**이행권고결정 이의 2주 — 소액사건심판법 조문 번호·기간 미검증, 확인 요망** ②**보충송달(가족 수령 시 효력) — 민소법 제186조 계열 미인용 서술, 확인 요망** ③지급명령 확정 후 구제(송달 하자·청구이의의 소) FAQ — 제도 존재 수준으로 완충 ④관할 이송 신청 — 일반론 ⑤"나의사건검색" 진위 확인 안내 — 시스템 명칭 확인. 답변서 30일·이의 2주·무변론(제256·257·470조)은 기검증 재사용
- **loan-recovery**: ①**민법 제603조(변제기 미정 시 상당 기간 최고 후 청구) — 직접 미검증, 확인 요망** ②민법 제162조(10년) — 표준 조문이나 이번 검증 대상 아님 ③"일부 변제 시 이자·원금 충당 순서" — 변제충당(민법 제479조 계열) 조문 미인용 ④대여 vs 투자 경계("원금 보장 약속" 축) — 법리 요약 ⑤"자연스러운 독촉의 기록화" 서술 — 증거 수집 조장으로 읽히지 않는지 수위 확인. 이자제한법 20%·민법 제379조 5%·상법 제54조 6%는 웹 검증 완료. 본문에 fraud-complaint 크로스 링크 삽입(렌더 확인)
- **provisional-remedies**: ①**제277조(보전의 필요) — 조문 인용했으나 문언 직접 미검증, 확인 요망** ②급여 압류 제한 — 범위 수치(민사집행법 제246조 계열) 미기재, "법으로 정해진 제한" 수준 ③해방공탁·이의신청 — 존재 언급 수준 ④"소명 vs 증명" 구분 서술 — 법리 요약 ⑤부당 보전 손해배상 — 기존 편들과 일관된 수위. 제287조(제소명령 2주 이상·불이행 시 취소)는 웹 검증 완료, 제276·300·292②·301조·제168조는 기검증 재사용. 본문에 construction/payment-claim 크로스 링크(렌더 확인)
- **payment-order**: ①**인지대 "소송의 10분의 1 수준" — 민사소송등인지법 제7조 계열 미검증, 확인 요망** ②이의 시 인지 차액 보정 — 실무 절차 서술(조문 미인용) ③"확정 시 확정판결과 같은 효력" — 제474조 미인용(제462·470·472조는 웹 검증 완료) ④소제기신청(송달불능 시 소송 전환) — 조문 미인용 ⑤실무 포인트 3종(직접 신청 사실 서술·주소 전제·신청서=소송기록)은 지시서 문구 그대로 이행 — "많다" 표현 미사용 확인
- **goods-payment**: ①**"애매한 용역 유형은 짧은 쪽 전제로 관리" — 안전 우선 서술이나 유형 분류(제163조 각 호 대 상법 제64조) 자체는 법리 판단 영역, 확인 요망** ②"입금 충당 특정" 실무 조언 — 변제충당 법리 배경(조문 미인용) ③"잔액확인서 = 승인 → 시효 재시작" — 제168조 적용 서술 수위 ④"추가 주문 지속 = 하자 반박 정황" — 실무 정황론 ⑤개인사업자 폐업 시 사업주 개인 청구 — 일반론. 제163조 제6호(물품 3년)·제164조(1년)는 웹 검증 완료. corporate 크로스 링크는 미발행이라 미삽입(언급만)

### divorce
- **divorce-procedure**: ①**협의이혼 확인 후 신고 기한 — 가족관계등록법(3개월 추정)의 조문·기간 미검증으로 "정해진 기간"으로 처리, 확인 요망** ②숙려기간 예외(폭력 등 급박 사정) — 제836조의2 단서 요약, 문언 미검증 ③이혼 후 재산분할 2년(제839조의2) — 조문 인용했으나 직접 미검증(2편에서 검증 예정) ④가사조사·사전처분·재산명시 — 세부 페이지 수위의 존재·역할 서술 ⑤불법 증거 수집 경고 — 수위 규칙 이행(조장 아닌 경고). 제836조의2(숙려 3개월/1개월)·제840조(6사유)·가사소송법 제50조(조정전치·예외)는 웹 검증 완료

- **property-division**: ①**2년 제척기간의 성격 — "기간 내에 법원에 청구해야 하는 기간"으로 서술(판례 법리이므로 조문 인용 없이 "다루어집니다"로 완충), 서술 수위 확인 요망** ②**퇴직금·연금의 분할 대상성 — 판례 법리 영역이라 표에 "혼인 기간에 대응하는 부분이 논의 대상"으로만 적고 근거 열 비움. 공적연금 분할(국민연금법 계열) 조문 기재 여부 판단 요망** ③전업주부 가사·양육 기여 인정 — 세부 페이지 확정 카피와 동일 수위로 서술(판례 출처 미표기) ④특유재산 경계가 흐려지는 경우(유지·증가 기여) — 법리 요약, 조문 미인용 ⑤채무의 분할 반영 기준(공동생활 목적 여부) — 조문 미인용 실무론 ⑥"재산분할 합의 후 재청구 곤란" FAQ — 합의의 효력 문제로 완충 서술. **민법 제839조의2(①②③항)·제830조(①②항)·제831조·제843조 준용·제839조의3(제406조 제2항 기간)·가사소송법 제48조의2·제48조의3·제62조·제63조는 웹 검증 완료**

- **custody-support**: ①**양육비 산정기준표 — 구조(합산 소득×자녀 나이 → 소득 비율 분담)만 서술하고 구간·금액은 미기재. 개정되는 표이므로 수치 기재 여부 판단 요망** ②**양육비이행관리원 제재(운전면허 정지·출국금지·명단공개) — 대상 기준(미지급 액수·횟수)이 하위 법령 개정 영역이라 수치 미기재, 현행 기준 확인 요망** ③"양육비 포기 ↔ 면접교섭 포기" 맞교환 합의의 효력 — 판례 법리 영역이라 "그대로 인정되지 않을 수 있습니다"로 완충, 수위 확인 요망 ④양육자 지정 실무 고려 요소(현재 양육 상태·주 양육자 기간·형제자매 비분리) — 실무론, 조문 미인용 ⑤재혼과 양육비의 관계 — 사정 변경 사유로 서술, 조문 미인용 ⑥면접교섭 이행명령의 한계(금전과 달리 직접 집행 불가) — 실무론. **민법 제837조(①②③④항)·제837조의2(①②③항)·제909조(제4·5항), 가사소송법 제64조·제67조 제1항(과태료 1,000만 원 이하)·제68조(정기금 3기 이상, 감치 30일 범위)는 웹 검증 완료.** 지시서의 **직접지급명령 용어 미사용** 준수 확인(0건), 이행 확보는 이행명령 중심으로 서술

### criminal-victim
- **criminal-complaint**: ①**제258조 처분 통지 — 조문 인용했으나 "7일" 미검증으로 숫자 뺌, 확인 요망** ②**이의신청 기간 제한 없음 여부 — 미검증, 4편에서 확정 필수** ③제236조 대리 고소 미검증 ④혐의없음≠무고(판례 요약) ⑤형사사법포털 명칭·기능 확인
- **fraud-complaint**: ①**특경법 제3조 가중 구간(5억/50억) 확인 — 구체 법정형(3년 이상/무기·5년 이상)은 미검증으로 미기재, 기재 여부 판단 요망** ②사기 공소시효 10년(형소법 제249조) — 조문 인용했으나 직접 미검증 ③기망 판단 기준("돈이 건네진 시점의 의사·능력") — 판례 법리 요약 ④일부 변제의 양면 평가(판례 수위) ⑤투자 손실 vs 투자 사기 경계 서술 ⑥"과장 고소의 무고 위험" 경고 수위
- **voice-phishing-victim**: ①**서면 피해구제 신청 기한 — 시행령상 구체 기한(14일 추정) 미검증으로 "금융회사가 안내하는 기한"으로 처리, 수치 기재 여부 판단 요망** ②**채권소멸공고 기간(2개월)·환급 결정 기한 — 미검증으로 "공고 기간·수개월 단위"로만 서술** ③비례 배분 환급 — 법 구조 요약 ④이의제기(명의인 측) 절차 — 조문 미인용 ⑤문화상품권 사용정지 — 실무 안내 수위 ⑥대면편취형 2023-11-17 시행 — 검증 완료
- **appeal-non-prosecution**: ①**이의신청 기간 제한 없음 — 웹 검증 완료 (1편 유보 지점 해결). 다만 입법 논의(기간 제한 신설) 진행 중인 영역이라 개정 모니터링 필요** ②이의신청 후 절차(검사 직접수사/보완수사요구) — 구조 요약 ③재정신청 인용률 낮음 서술 — 실무 일반론 ④기소유예 불복 구조 FAQ — 법리 요약 ⑤열람·등사 절차 — 조문 미인용. **항고 30일(검찰청법 제10조)·재정신청 10일·항고전치 예외 3종(형소법 제260조)은 웹 검증 완료. 제258조 존재도 검찰청법 제10조 검증 중 간접 확인됨(1편 검토 항목 부분 해소)**
