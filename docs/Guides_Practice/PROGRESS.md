- **goods-payment**: ①**"애매한 용역 유형은 짧은 쪽 전제로 관리" — 안전 우선 서술이나 유형 분류(제163조 각 호 대 상법 제64조) 자체는 법리 판단 영역, 확인 요망** ②"입금 충당 특정" 실무 조언 — 변제충당 법리 배경(조문 미인용) ③"잔액확인서 = 승인 → 시효 재시작" — 제168조 적용 서술 수위 ④"추가 주문 지속 = 하자 반박 정황" — 실무 정황론 ⑤개인사업자 폐업 시 사업주 개인 청구 — 일반론. 제163조 제6호(물품 3년)·제164조(1년)는 웹 검증 완료. corporate 크로스 링크는 미발행이라 미삽입(언급만)

### divorce
- **divorce-procedure**: ①**협의이혼 확인 후 신고 기한 — 가족관계등록법(3개월 추정)의 조문·기간 미검증으로 "정해진 기간"으로 처리, 확인 요망** ②숙려기간 예외(폭력 등 급박 사정) — 제836조의2 단서 요약, 문언 미검증 ③이혼 후 재산분할 2년(제839조의2) — 조문 인용했으나 직접 미검증(2편에서 검증 예정) ④가사조사·사전처분·재산명시 — 세부 페이지 수위의 존재·역할 서술 ⑤불법 증거 수집 경고 — 수위 규칙 이행(조장 아닌 경고). 제836조의2(숙려 3개월/1개월)·제840조(6사유)·가사소송법 제50조(조정전치·예외)는 웹 검증 완료

- **property-division**: ①**2년 제척기간의 성격 — "기간 내에 법원에 청구해야 하는 기간"으로 서술(판례 법리이므로 조문 인용 없이 "다루어집니다"로 완충), 서술 수위 확인 요망** ②**퇴직금·연금의 분할 대상성 — 판례 법리 영역이라 표에 "혼인 기간에 대응하는 부분이 논의 대상"으로만 적고 근거 열 비움. 공적연금 분할(국민연금법 계열) 조문 기재 여부 판단 요망** ③전업주부 가사·양육 기여 인정 — 세부 페이지 확정 카피와 동일 수위로 서술(판례 출처 미표기) ④특유재산 경계가 흐려지는 경우(유지·증가 기여) — 법리 요약, 조문 미인용 ⑤채무의 분할 반영 기준(공동생활 목적 여부) — 조문 미인용 실무론 ⑥"재산분할 합의 후 재청구 곤란" FAQ — 합의의 효력 문제로 완충 서술. **민법 제839조의2(①②③항)·제830조(①②항)·제831조·제843조 준용·제839조의3(제406조 제2항 기간)·가사소송법 제48조의2·제48조의3·제62조·제63조는 웹 검증 완료**

- **custody-support**: ①**양육비 산정기준표 — 구조(합산 소득×자녀 나이 → 소득 비율 분담)만 서술하고 구간·금액은 미기재. 개정되는 표이므로 수치 기재 여부 판단 요망** ②**양육비이행관리원 제재(운전면허 정지·출국금지·명단공개) — 대상 기준(미지급 액수·횟수)이 하위 법령 개정 영역이라 수치 미기재, 현행 기준 확인 요망** ③"양육비 포기 ↔ 면접교섭 포기" 맞교환 합의의 효력 — 판례 법리 영역이라 "그대로 인정되지 않을 수 있습니다"로 완충, 수위 확인 요망 ④양육자 지정 실무 고려 요소(현재 양육 상태·주 양육자 기간·형제자매 비분리) — 실무론, 조문 미인용 ⑤재혼과 양육비의 관계 — 사정 변경 사유로 서술, 조문 미인용 ⑥면접교섭 이행명령의 한계(금전과 달리 직접 집행 불가) — 실무론. **민법 제837조(①②③④항)·제837조의2(①②③항)·제909조(제4·5항), 가사소송법 제64조·제67조 제1항(과태료 1,000만 원 이하)·제68조(정기금 3기 이상, 감치 30일 범위)는 웹 검증 완료.** 지시서의 **직접지급명령 용어 미사용** 준수 확인(0건), 이행 확보는 이행명령 중심으로 서술

- **alimony**: ①**위자료 액수의 실제 규모 — 지시서의 "과장 금지"에 따라 "재산분할보다 작다", "기대에 못 미치는 경우가 많다"로만 서술하고 구체적 금액대는 미기재. 범위 제시 여부 판단 요망** ②쌍방 유책 시 책임의 경중 비교, 파탄 후 발생한 사정의 평가 — 판례 법리 영역이라 조문 인용 없이 일반론으로 서술, 수위 확인 요망 ③배우자 직계존속에 대한 청구 "인정 범위가 좁다" — 실무론 ④위자료의 과세 취급(손해배상 성격/대물 지급 시 별도 세금) — 세법 영역, 서술 수위 및 정확성 확인 요망 ⑤지연손해금 발생 서술 — 조문 미인용 ⑥"합의로 위자료 포기 후 재청구 곤란" FAQ — 합의 효력 문제로 완충. **민법 제806조(①③항)·제843조 준용·제766조(①항 3년, ②항 10년 — 조문 원문으로 직접 확인)·제840조·제839조의2 제3항은 웹 검증 완료.** 지시서 요구사항인 불법 수집 증거의 역풍 경고는 Callout으로 반영, 상간자 청구는 5편으로 이관

- **adultery-claim**: ①**"이미 파탄된 뒤라면 책임이 인정되지 않을 수 있다" — 판례 법리를 제750조의 인과관계 요건에서 도출하는 방식으로 서술(판례 인용 없음). 수위 확인 요망** ②**"기혼임을 알았거나 알 수 있었을 것"의 고의·과실 판단 — 판례 법리를 제750조 요건으로 환원해 서술, 확인 요망** ③"부정한 행위는 성관계에 한정되지 않는다"(제840조 제1호) — 개념 범위 서술, 판례 영역이라 경계는 "사건마다 다투어진다"로 완충 ④상간자 위자료 액수 "크지 않은 것이 보통" — 실무론, 금액 미기재 ⑤상간자만 청구 시 일반 민사 사건으로 처리된다는 서술 — 관할 실무, 조문 미인용 ⑥연대 책임에서 상간자의 구상 문제 — 존재 언급 수준. **민법 제750조·제751조 제1항·제760조 제1항·제766조(①②항)·제840조 제1호는 웹 검증 완료. 간통죄 폐지(형법 제241조 삭제)도 검증 완료 — 헌재 사건번호는 미기재.** 지시서 요구인 신상 공개·직장 통보의 역풍 경고를 별도 Callout으로 반영(이 편의 핵심 안전장치)

- **international-divorce**: ①**체류 자격 서술 — 지시서가 "출입국 영역 경계, 수위는 확인 필요"로 지정한 부분. "이혼했다고 자동으로 체류가 종료되지 않는다"와 고려 사정 3가지(파탄 책임·자녀 양육·생활 기반)만 적고 구체 요건·비자 종류(F-6 등)는 미기재. Callout으로 "출입국 소관, 별도 확인" 명시. 수위 확인 필수** ②**본문에 "법무법인 명은 영어로 직접 상담이 가능하다"는 한 문장 포함 — 지시서 요구사항이나 가이드 표준의 "본문 광고 금지, 광고는 말미 CTA 하나뿐"과 충돌. 존치 여부 판단 요망** ③외국 판결의 승인·집행 요건 — 제도 존재 수준으로만 서술, 민사소송법 제217조 계열 조문 미인용 ④국제적 아동반환 절차(헤이그 협약 계열) — 명칭·조문 없이 "국제적으로 마련된 반환 절차"로만 언급 ⑤외국에서 이혼 성립 시 가족관계등록 신고 — 기간 미검증으로 수치 미기재 ⑥"먼저 움직이는 쪽이 유리한 국면" 서술 — 실무론. **국제사법 제56조 제1항(1~4호)·제2항, 제64조(1~3호), 제66조(단서 포함)는 조문 원문으로 직접 확인 완료(2022년 전부개정 반영). 민법 제839조의2 제3항·제766조 제1항은 기검증 재사용**

- **divorce-preparation**: ①**"준비의 수준이 이후 모든 단계의 결과에 영향을 준다" — 지시서의 "먼저 상담한 쪽에 유리한 것도 사실" 요구를 세부 페이지 문구 수위로 옮긴 것. 상대를 앞지르라는 톤이 되지 않게 완충했으나 표현 확인 요망** ②별거 중 부양 의무 존속 — "곧바로 사라지지 않는다" 수준, 조문 미인용 ③일방적 가출이 불리하게 평가될 수 있다는 서술(악의의 유기 계열) — 죄명·조문 단정 없이 "다투어질 수 있다"로 처리 ④"배우자 명의 부동산 등기부등본은 누구나 열람 가능" — 사실 확인 요망 ⑤부부 간 각서·합의서의 효력 — 사안별 판단으로 완충 ⑥자녀를 자료 수집에 끌어들이지 말라는 당부 — 실무·수위 규칙 반영. **민법 제836조의2·제839조의2 제3항·제766조 제1항·제837조 제2항은 기검증 재사용(신규 검증 없음).** 감시·미행 조장 서술 금지 규칙 준수 확인

### inheritance
- **renunciation**: ①**선순위 상속인 전원이 포기하면 다음 순위로 넘어간다는 서술 — 제1043조는 "같은 순위 내 귀속"만 규정하고 순위 이전은 제1000조 순위 구조에서 도출되는 해석이라 조문 직접 인용 없이 서술. 수위 확인 요망** ②"처분행위"로 평가될 수 있는 행위의 예시(예금 인출·명의 이전·유품 처분) 및 장례비 등 경계 — 판례 법리 영역이라 "사안에 따라 다르게 판단된다"로 완충, 예시 적정성 확인 요망 ③특별한정승인의 "중대한 과실" 판단 — 요건만 적고 기준은 미서술 ④한정승인 신고 관할(피상속인 최후 주소지 가정법원)·제출 서류 — 실무 서술, 조문 미인용 ⑤"수익자가 지정된 보험금은 성격이 다를 수 있다" FAQ — 개별 확인 필요로 완충 ⑥2편(asset-search) 미발행이라 안심상속 원스톱을 FAQ에서 명칭 없이 "행정 절차"로만 언급, 신청 기간 수치 미기재. **민법 제1019조(①②③④항)·제1026조(1~3호)·제1032조 제1항(5일·2개월)·제1042조·제1043조는 조문 원문으로 직접 확인 완료.** 수임료·정액 안내는 본문에 넣지 않음(광고 금지 규칙), 수행 경험 암시 표현 0건

- **asset-search**: ①**안심상속 신청 자격의 세부(2순위의 온라인 제한, 1순위 포기로 넘어온 2순위는 방문만) — 행정 실무 안내 페이지 기준으로 서술, 변동 가능 영역이라 현행 확인 요망** ②**신청 기한 "사망일이 속한 달의 말일부터 1년" — 웹 검증 완료(정부24·행안부), 다만 행정 서비스라 개편 시 갱신 필요** ③조회 범위 표(금융·토지·자동차·세금·연금) — 행정 안내 기준, 항목 변동 가능 ④"금융거래 조회는 기관별 통보" 서술 — 실무 안내 수위 ⑤사망신고 동시 신청 권장·준비 서류 — 행정 실무, 세부는 "방문 전 확인" 완충 ⑥상속인 금융거래 조회(금융감독원 계열) — FAQ에서 명칭 없이 "별도의 상속인 조회 제도"로만 언급 ⑦"49재 무렵이면 두 달 경과" 서술 — 생활 감각 서술, 문제없는지 확인. **민법 제1019조 제1·2항, 제1026조 제1·2호는 기검증 재사용.** 셀프 가능 행정 절차의 사실 서술은 표준 §2 예외(지시서 명시) 적용 — "상속인이 직접 신청할 수 있습니다" 명시
