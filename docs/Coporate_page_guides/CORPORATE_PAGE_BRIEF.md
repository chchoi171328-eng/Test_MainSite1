# 기업 법무 세부 페이지 재정의 지시서 (Claude Code용)

> 결정: 분야명·슬롯은 유지하되 페이지의 정체성을 **자문 중심 → 분쟁 중심**으로
> 재정의한다. 근거: 한국 중소기업 시장 현실 — 자문·계약검토 지출이 드물고,
> 소형 사무소의 기업 업무는 대부분 분쟁·소송·공정위 대응이다.
> 수위 확정: **공정위 조사 대응 자문 = 수행 경험 사실 서술 가능 / 공정위 신고
> 대리 = 실적·경험으로 서술 금지** (업무 절차 정보로만 다룸).

## [작업 1] /practice/corporate 재구성

**§1 헤드라인 방향** (기존 자문 톤 교체)
> 회사가 분쟁에 휘말렸을 때 — 사내변호사를 해본 변호사가 다룹니다.
> (서브) 대금, 하도급, 노무, 중대재해. 회사의 분쟁은 개인의 소송과 다르게 움직입니다.

**§2 다루는 일 (분쟁 우선 재배열)**
1. **기업 간 대금 분쟁** — 물품·용역대금 회수와 방어 (민사 물품대금 편과
   거울상: 거긴 개인·소상공인 어조, 여긴 기업 어조 — 상호 링크)
2. **하도급법 분쟁·공정위 대응** — 하도급대금, 부당 단가인하, 부당특약.
   소송 대응과 공정위 절차. 서술 예: "공정위 조사 단계의 대응을 자문해
   왔습니다" (사실 수위 — 신고 대리 실적 서술 금지)
3. **노무 분쟁 — 사용자 측 대응** — 임금체불 진정(노동청), 부당해고
   구제신청(노동위원회). 근로자 측 청구는 민사 분야가 담당 (거울상 원칙 명시)
4. **중대재해 — 사고 초동·수사 대응** — 형사 성격이지만 **찾는 사람이
   기업이므로 입구는 여기** (형사 페이지와 상호 링크)
5. **계약서 검토·자문** — 하단 보조 항목으로 강등 배치. 기존 경계 문구
   유지(검토와 수정안 작성은 별개 업무, 추가 비용 사전 안내). "분쟁을 겪은
   뒤 다음 계약을 고치러 오시는 경우가 많습니다" 톤 허용
6. 법인 설립·등기 등은 한 줄 안내 수준

**§3 상호 링크** — 플랜트 특화 페이지(협력사 하도급 맥락), 건설(하도급대금
직접청구 = 대금 회수는 건설 소관), 형사(중대재해 수사), 민사(물품대금)

**§4 수임료** — 표기 보강: "기업 분쟁 사건(대금·하도급·노무)은 민사 소송
착수금 기준을 따릅니다" 한 줄 + 자문은 기존 시간당 유지.
수임료 페이지(/fees)에도 같은 한 줄이 필요한지 확인 — 기업 항목이 시간당만
있다면 분쟁 사건 기준 준용 문구 추가
