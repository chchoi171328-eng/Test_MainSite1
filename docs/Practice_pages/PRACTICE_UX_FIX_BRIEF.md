# 업무분야·메뉴·수임료 UX 수정 지시서 (Claude Code용)

> 배포 후 실사용 검토에서 나온 5건의 수정. 상위 기준: FIELD_MASTER_PLAN.md.
> 카피 신규 작성이 필요한 곳은 본 문서의 문구를 글자 그대로 사용한다.

## [수정 1] 업무 분야 카드 — 크기 통일

- 대상: 홈 업무 분야 섹션 + /practice 카드 그리드
- 현재 위/아래 그룹의 카드 크기가 다른 구조를 **전 카드 동일 크기 그리드로 통일**한다.
- **카드 순서는 변경하지 않는다.** 현행 순서(형사 → 민사 → 가사(이혼·상속) → 부동산 →
  건설·공사대금 → 기업)는 마스터 플랜 §1의 그물 원칙(지역 수요 분야 우선)에 따른 것으로
  그대로 유지한다. 크기만 통일한다.
- 카드 내부 구성(제목·설명·세부 키워드)은 변경하지 않는다.

## [수정 2] 카드 전체 클릭 영역

- 카드 아무 곳이나 클릭해도 해당 세부 페이지로 이동하게 한다 (stretched-link 패턴 등).
- 접근성: 카드당 링크는 하나의 a 요소가 대표하고, 카드 전체가 시각적 hover 상태를 가진다.
- **주의**: 카드 안의 세부 키워드 중 별도 링크가 있는 항목(가사 카드의 "상속 분쟁"
  → /practice/inheritance)은 독립 클릭 영역으로 유지한다. 키워드 클릭이 카드 전체
  링크로 삼켜지지 않도록 z-index/이벤트 처리를 확인한다.

## [수정 3] 이혼 페이지 — 상속 분기 라인 추가

- 대상: /practice/divorce 도입 섹션 끝
- 도입 마지막 문단 뒤에 분기 라인 한 줄을 추가한다 (형사 페이지의 피해자 분기와 동일 문법):
  - 문구: `상속 문제로 오신 분은 상속 안내에서 확인하실 수 있습니다.`
  - "상속 안내"에 링크: /practice/inheritance
  - 스타일: 본문보다 작게(14px 안팎), 보조 톤 — 형사 페이지의 피해자 분기 라인과 동일 스타일 재사용
- 카피 원천: divorce-page-preview.html (갱신본, 도입부에 반영되어 있음)

## [수정 4] 상단 메뉴 — 업무 분야 드롭다운

- "업무 분야" 메뉴에 법률정보와 동일한 방식의 드롭다운을 추가한다.
- 항목과 순서 (현행 카드 순서 기준, 가사 카드는 이혼/상속으로 분리 표기):
  1. 형사 변호 — /practice/criminal
  2. 형사 피해자·고소 — /practice/criminal-victim
  3. 민사 소송 — /practice/civil
  4. 이혼 — /practice/divorce
  5. 상속 — /practice/inheritance
  6. 부동산 — /practice/real-estate
  7. 건설·공사대금 — /practice/construction
  8. 기업 법무 — /practice/corporate
  9. (구분선) 업무 분야 전체 보기 — /practice
- "업무 분야" 라벨 자체 클릭 시 /practice 이동 (기존 동작 유지).
- 모바일 메뉴에도 동일한 하위 항목을 노출한다 (아코디언 등 기존 모바일 메뉴 패턴 준수).

## [수정 5] 수임료 페이지 — 분야 표를 8분야 체계로 정렬

- 현재 표는 3행(형사 / 이혼·가사 / 민사(대여금·계약 분쟁))으로, 세부 페이지 8종과
  어긋난다. 각 세부 페이지의 "수임료 자세히 보기"가 이 페이지로 연결되므로,
  **세부 페이지에서 온 방문자가 자기 분야 행을 반드시 찾을 수 있어야 한다.**
- 표를 아래 행으로 교체한다 (금액은 각 세부 페이지 수임료 박스와 동일 — 불일치 금지):

| 분야 | 착수금 기준 |
|---|---|
| 형사 변호 | 400~1,200만 원 |
| 형사 피해자·고소 | 400~1,000만 원 |
| 민사 소송 | 300만 원부터 |
| 부동산 | 300만 원부터 |
| 건설·공사대금 | 400만 원부터 |
| 이혼 | 400~700만 원 |
| 상속 분쟁 | 400만 원부터 |
| 상속포기 / 한정승인 | 10만 원 / 100만 원 (정액) |
| 기업 법무 | 자문료 시간당 25만 원 |

- 민사 행의 괄호 예시("(대여금·계약 분쟁)")는 **삭제**한다 — 분야 예시는 각 세부
  페이지가 담당한다. 다른 행에도 괄호 예시를 넣지 않는다.
- 각 행에서 해당 세부 페이지로 링크를 건다 (행 클릭 또는 분야명 링크).
- 기존 공통 문구 유지: "위 금액은 부가세 별도입니다." + 상담료 표기.
- 한정승인 행 각주: "정리할 재산이 특별히 많은 경우 사건 검토 시 증액된 금액을
  미리 안내드립니다." (상속 페이지와 동일 문구)
- 기업 행 각주: "착수 전에 예상 시간과 총액을 먼저 안내드립니다." (기업 페이지와 동일 취지)
