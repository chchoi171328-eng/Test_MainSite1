## [작업 1] 홈 "어떤 상황이신가요?" 섹션 (방식 A)

### 위치
- 히어로 바로 아래, 철학 섹션("'이겨드립니다'라는 말은 쉽습니다...") 위에 삽입.
- 홈 전용 섹션이다. 다른 페이지에 렌더링하지 않는다.

### 섹션 구조 (기존 홈 섹션들과 동일한 규격)
- 영문 라벨(eyebrow): `How Can We Help` — Playfair, 골드, 소형
- 제목(h2, 명조): `어떤 상황이신가요?`
- 리드 문구: `지금 상황과 가장 가까운 문장을 선택하세요.`
- 상황문 리스트: 아래 8 + 1행. 세로 리스트, 각 행 전체가 클릭 영역.

### 상황문 카피와 링크 타겟 (글자 그대로, 순서 고정)

| # | 상황문 | 우측 표기 | 링크 |
|---|---|---|---|
| 1 | 경찰 조사를 앞두고 있거나, 가족이 조사를 받고 있습니다 | 형사 | /practice/criminal |
| 2 | 사기·폭행 등 범죄 피해를 입어 고소를 생각하고 있습니다 | 형사 피해자 | /practice/criminal-victim |
| 3 | 빌려준 돈, 받을 돈을 받지 못하고 있습니다 | 민사 | /practice/civil |
| 4 | 법원에서 소장이나 지급명령서를 받았습니다 | 민사 | /practice/civil#sued |
| 5 | 이혼을 생각 중이거나, 배우자가 이혼을 요구합니다 | 이혼 | /practice/divorce |
| 6 | 상속 분쟁이 있거나, 돌아가신 분의 빚이 걱정됩니다 | 상속 | /practice/inheritance |
| 7 | 임대차·매매·토지 등 부동산 문제가 있습니다 | 부동산 | /practice/real-estate |
| 8 | 공사대금·하도급대금 분쟁이 있습니다 | 건설 | /practice/construction |
| 8 | 어떤 문제인지 잘 모르겠습니다 | — | /consultation |

- 9행(잘 모르겠습니다)은 시각적으로 구분한다: 배경색 약하게(옅은 골드 톤), 굵은 글씨,
  아래 힌트 문장 추가: `분류하지 않으셔도 됩니다. 먼저 편하게 물어보세요.`
- 앵커 ID(`#victim`, `#sued`)는 세부 페이지 지침에서 해당 섹션에 부여될
  예약 ID다. 이 지침에서는 링크만 걸고, ID 생성은 세부 페이지 작업에서 한다.

### 스타일
- 각 행: 상황문(주, brand-dark, 500) + 우측 분야 표기(보조, 소형 회색) + 골드 화살표.
- 호버 시 배경 옅게 변화. 밑줄 없음.
- 모바일: 우측 분야 표기는 숨겨도 된다 (상황문이 주인공).
- 행 높이·간격은 터치 타겟 44px 이상.

## [작업 2] 업무 분야 카드 상황문 (병행)

### 조건 렌더링 — 중요
- 카드 컴포넌트에 상황문(질문형) 한 줄을 추가하되,
  **/practice 페이지에서만 렌더링하고 홈의 업무 분야 섹션에서는 숨긴다.**
- 이유: 홈에는 [작업 1] 섹션이 이미 상황문을 노출하므로, 같은 화면에
  유사 문장이 두 번 보이면 안 된다.

### 카드별 질문형 카피 (글자 그대로)
- 형사 변호: `경찰 조사를 앞두고 계시거나, 고소를 생각하고 계신가요?`
- 민사 소송: `받을 돈이 있거나, 법원에서 소장을 받으셨나요?`
- 가사(이혼·상속): `이혼을 생각 중이시거나, 상속 문제가 생기셨나요?`
- 부동산·건설: `임대차·매매 분쟁이나 공사대금 문제가 있으신가요?`
- 기업 법무: `회사 운영 중 법률 문제가 생기셨나요?`
- 기타: `어떤 문제인지 잘 모르겠으신가요?`

### 배치·스타일
- 위치: 카드 분야명(제목) 바로 아래, 기존 설명문 위.
- 스타일: 설명문보다 살짝 강조 (골드 톤 또는 진한 색, 500 weight), 물음표로 끝남.
- 카드의 기존 구조(분야명·설명·세부 키워드)는 변경하지 않는다.
- 부동산·건설 카드의 분리 여부는 이 작업 범위가 아니다. 세부 페이지
  지침에서 결정한다. 이 작업에서는 현행 카드 6개 구조를 유지한다.

## [작업 3] 부수 정리

1. 홈의 업무 분야 섹션은 [작업 1] 섹션과 역할이 겹치지 않도록
   **분야명 중심의 축약 미리보기**로 유지한다 (카드 상황문 숨김 확인).
2. 상황문 텍스트는 실제 텍스트 노드로 렌더링한다 (이미지·SVG 텍스트 금지 — SEO).
3. 접근성: 리스트는 nav 또는 ul 시맨틱 사용, 각 행은 a 태그,
   aria-label 불필요 (문장 자체가 레이블).

## 금지
- 상황문에 감정 수식어("억울하게", "황당하게") 추가 금지.
- 행 추가·순서 변경·문구 수정 금지. 변경 필요 시 보고 후 승인.
- 9행(잘 모르겠습니다)을 일반 행과 같은 스타일로 처리하지 말 것 (구분 필수).
- CTA 버튼("지금 상담", "빠른 상담") 형태로 변형 금지 — 이 섹션은 안내지 촉구가 아니다.
