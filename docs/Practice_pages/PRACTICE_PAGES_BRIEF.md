# 업무 분야 세부 페이지 작성 지침서 (Claude Code용)

> 상위 기준: **FIELD_MASTER_PLAN.md** (충돌 시 그쪽이 우선)
> 카피 원천: 각 페이지의 미리보기 HTML 파일. **본문 카피는 미리보기의 글자를 그대로
> 사용한다. 임의 수정·요약·어투 변경 금지.** 디자인·컴포넌트도 미리보기의 시각 구조를
> 따른다 (기존 사이트 토큰과 통합하되 위계·간격·구성 유지).
> **파일 전달**: 이 지침서와 §3 상태 표의 미리보기 HTML 전부를 같은 폴더(예:
> /docs/previews/)에 두고 작업한다. HTML이 없는 페이지는 구현하지 않는다.
> **정본 관리**: 카피 수정은 미리보기 HTML을 고친 뒤 사이트에 재반영하는 순서로만
> 진행한다. 사이트 코드만 고쳐 정본과 어긋나게 만들지 않는다.
> 이 문서는 페이지가 확정될 때마다 갱신된다. §3의 상태 표에서 "확정"인 페이지만 구현한다.

## 1. 공통 구현 규칙

### 1-1. 라우트·배포
- 라우트는 /practice/ 하위에 생성한다 (마스터 플랜 1-3의 8종 URL 기준).
- 작업은 브랜치에서 진행하고, **머지·배포는 8종 전체 확정 + 상황 라우팅과 동시**가
  기본이다 (마스터 플랜 실행 순서 5). 조기 배포가 필요하면 별도 지시를 기다린다.
- 기존 /practice(업무 분야 목록)의 카드는 아직 세부 페이지로 링크하지 않는다.
  링크 연결은 동시 배포 시점에 일괄 적용한다.

### 1-2. 공통 템플릿 컴포넌트 (1회 구현, 전 페이지 재사용)
미리보기 HTML의 구조를 컴포넌트화한다:
- `PracticeHeader` — 단색형(#222 배경 + 하단 골드 1px), 브레드크럼 + 명조 h1 + 서브 문구
- `SituationList` — 원형 불릿 리스트, 그룹 구분(.grp = 상단 여백+구분선) 지원
- `ProcedureTimeline` — 번호 원형 + 단계명(명조) + 설명 + "할 수 있는 것" 박스(연갈색 배경)
- `AnchorSection` — 연배경(#faf9f6) 강조 섹션, id 앵커
- `FaqAccordion` — details/summary 시맨틱 유지, +/− 토글
- `CaseCards` — 분야 태그 + 결과 배지 + 제목 (아래 1-4 데이터 연동 규칙 적용)
- `FeeBox` — 요소 순서 고정: 금액(명조) → 부가세 註(`표시 금액은 부가세(VAT) 별도입니다`,
  소형 회색, 전 페이지 공통) → 설명 → 약속 문구(구분선 위) → 전문분야 한 줄(cert, 옵션)
- `ResourceList` — 도구·글 링크 목록
- `PracticeCta` — 다크 배경, 리드 문구 + 전화/온라인 버튼 + 지역 문구

### 1-3. 미리보기 → 실제 페이지 변환 시 제거·치환할 것
- 상단 review-note 배너 제거
- "(실제 링크: ...)" 회색 주석 제거하고 해당 href를 실제 경로로 연결
- cert 옆 "<!-- 등록증 표기가 다르면 그대로 교체 -->" 주석 제거
- 미리보기의 내장 nav/footer 제거하고 사이트 공통 레이아웃 사용
- tel 링크·상담 버튼은 사이트 공통 값 사용

### 1-4. 성공사례 카드 데이터 규칙 (중요)
- 미리보기의 사례 카드는 **표시 예시**다. 실제 페이지에서는 DB의 실제 사례를
  분야 태그로 필터해 최신 3건을 표시한다 (list_title·result_label 사용).
- **해당 분야의 실제 사례가 없으면 섹션 전체를 렌더링하지 않는다.**
  존재하지 않는 사례를 예시로 노출하는 것은 금지 (허위 표시 리스크).
  ※ 현재 DB는 형사 39건뿐이므로, 민사·피해자 페이지의 사례 섹션은 사례 보충
  전까지 자동으로 숨겨진다. 정상 동작이다.
- "사례 더 보기 →"는 /cases의 해당 분야 필터로 연결한다.

### 1-5. SEO 공통
- 페이지별 title·meta description·og:title은 §2 사양표의 값을 사용한다.
- FAQ 섹션에 FAQPage JSON-LD 구조화 데이터를 삽입한다 (질문·답변 = 화면 텍스트와 동일).
- h1은 페이지당 1개(헤더의 한글 제목). 섹션 제목은 h2.
- 본문 내 링크(도구·수임료·사례·형제 페이지)는 모두 내부 링크로 연결한다.

### 1-6. 검증 (페이지마다)
- [ ] 카피가 미리보기와 글자 단위 일치
- [ ] 모바일에서 타임라인·리스트·FAQ 확인
- [ ] 앵커 링크(#sued 등) 스크롤 동작
- [ ] 사례 섹션: 실데이터 연동, 0건 시 미렌더링
- [ ] JSON-LD 유효성
